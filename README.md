# Facebook & Instagram Ad Performance Dashboard

## 📊 Overview
This repository contains a **Power BI dashboard** designed to analyze advertising performance across **Facebook and Instagram**.  
It provides **comprehensive insights** into campaign metrics, audience demographics, and ad type effectiveness, enabling digital marketers to optimize strategies for these two platforms.

---

## 🚀 Features
- **Campaign KPIs**
  - Impressions, Clicks, Shares, Comments, Purchases
  - CTR (Click Through Rate), Engagement Rate, Conversion Rate, Purchase Rate
- **Budget Analysis**
  - Total budget allocation
  - Average budget per campaign
- **Demographic Insights**
  - Engagements by gender (male vs female distribution)
  - Engagements by age groups (20–50 years)
  - Engagements by country (global map visualization)
- **Trend Analysis**
  - Weekly engagement trends
  - Hourly engagement fluctuations
- **Ad Type Performance**
  - Carousel, Image, Stories, Video ads compared across CTR, ER, CR, PR

## 📈 Key Insights
- Female audiences showed **higher engagement (37%)** compared to male audiences (27%).
- **Video ads** achieved the highest conversion rate (5.56%), despite lower impressions.
- Engagement peaked during **specific hours and weekdays**, highlighting optimal posting times.
- Carousel and Image ads delivered **consistent CTR (~11%)**, making them reliable formats.
